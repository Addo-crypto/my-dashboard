# Addo.corp

Personal dashboards and portfolio of **Shepherd Addo Anokye**: dashboard specialist, full-stack developer, AI builder and trader, with 5 years in computing and AI.

Three versions of the same content, each in a different design style:

| Version | Folder | Style |
|---|---|---|
| Studio | `/` (this folder) | Light, clean designer portfolio. The public face. |
| Glass | `/glass/` | Dark frosted-glass analytics dashboard with switchable views. |
| Neon | `/neon/` | Cyberpunk neon landing page with HUD panels. |

## What's inside

- Profile, availability and contact details (email, WhatsApp, Facebook, Instagram, with QR codes)
- ADDO, the in-house AI agent: 24 capabilities across 8 build stages, with a chart and a searchable index
- Services, with dashboards as the specialty
- Trading: markets, method and a trade journal with a running profit and loss chart
- AI skills and the ADDO AI stack
- Build planner with time estimates, and the five-step project process

## Run it

Each version is a single self-contained HTML file plus its images. Open `index.html` in a browser, or turn on **GitHub Pages** (Settings → Pages → Deploy from branch → `main`, folder `/`). The site is then live at `https://addo-crypto.github.io/my-dashboard/`.

## Notes

- Profile editing (email and password sign-in) works in the versions hosted on Claude, where an online database backs it. On GitHub Pages and other plain hosting, the edit controls stay hidden and the default profile shows.
- The trade journal and planner save in each visitor's own browser.

Built with HTML, CSS and JavaScript, using Google Fonts (Lexend, Anton, Chakra Petch, Exo 2, Outfit, Manrope).
