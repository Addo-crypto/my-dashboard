Flagship: ADDO, a Jarvis-style AI agent

A conversational agent in Python and Flask on the Claude API. It answers by voice to its wake word, reads images, works with Gmail and Calendar, writes and runs websites, pushes them to GitHub and stores data in SQLite, Supabase or Firebase. It runs privately on a Windows PC and is reachable from a phone over Tailscale.
